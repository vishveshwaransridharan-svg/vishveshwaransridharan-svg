## Latest team build

Recovery Desk, built at Autonomous SG 2026 (Airbus Challenge 2). We built an airport recovery simulator where ATC, pilot and ground agents negotiate revised landing plans, supported by a CP-SAT solver and an operator dashboard. We also built ESP32 prototype flight-display nodes with a TFT, motion-triggered disruption input and an emergency button, using HTTP event/status messages.
